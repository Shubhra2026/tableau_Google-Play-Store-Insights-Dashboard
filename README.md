# Google Play Store Insights Dashboard

## Project Overview

The **Google Play Store Insights Dashboard** is a data visualization and analytics project developed using Tableau. The dashboard provides meaningful insights into Google Play Store applications by analyzing app categories, ratings, installs, and content ratings.

This project demonstrates how business intelligence and data visualization techniques can be used to understand app market trends, user preferences, and app performance metrics.

---

## Objective

The primary objective of this project is to:

- Analyze Google Play Store application data
- Identify trends in app categories and installs
- Evaluate user ratings across categories
- Visualize app distribution by content rating
- Highlight top-performing applications
- Build an interactive dashboard for business insights

---

## Tools & Technologies Used

- Tableau
- Data Cleaning & Transformation
- Exploratory Data Analysis (EDA)
- Data Visualization
- Business Intelligence Techniques

---

## Dataset Information

The dataset contains information related to Google Play Store applications, including:

- App Name
- Category
- Rating
- Installs
- Reviews
- Content Rating
- App Type (Free/Paid)
- Genres
- Last Updated
- Size

---

## Dashboard Features

### 1. Apps by Content Rating
Displays the distribution of applications based on content rating categories.

### 2. Average Rating by Category
Shows average app ratings across different app categories.

### 3. Top Categories Count
Highlights categories with the highest number of applications.

### 4. Top 10 Apps
Displays the top-performing applications based on installs or ratings.

### 5. KPI Cards
Key performance indicators including:
- Total Apps
- Total Installs
- Average Ratings

### 6. Pie Chart Visualization
Represents app distribution and category contribution visually.

---

## Key Insights

- Categories like **Games**, **Tools**, and **Entertainment** dominate the Play Store market.
- Applications with higher user engagement generally receive better ratings.
- Free applications tend to attract more installs compared to paid applications.
- Content ratings influence app audience reach and install counts.
- Highly rated apps usually maintain strong review volumes and frequent updates.
